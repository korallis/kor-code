# Edit prose

Preserve the author's meaning and required facts. Remove generic praise, vague attributions, filler introductions, and conclusions that repeat the body.
Replace inflated words with ordinary ones: use, help, show, and improve. Delete empty phrases such as "it is important to note".
Keep the same name for the same concept. Replace abstract metaphors with the concrete action or state.
Break repetitive sentence patterns. Vary sentence lengths without adding content.
Use headings and lists only when they help readers find or compare information. Remove decorative emphasis and unnecessary em dashes.
Read the result aloud. Finish when the prose is specific, direct, and faithful to the original facts.
